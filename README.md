# The Library

A simple application to manage a library.

## Key features

- Manage books: Adding, removing, editing, viewing and searching books
- Users: Creating, editing, deleting and viewing user profiles
  - Only the authenticated user can make changes to one's profile
- Borowing books
  - Admin can mention in the system that a user has borrowed and returned a book
  - The user can see the current book and the history of books borrowed
  - The user can also see when to return books and what books invovle late fees
